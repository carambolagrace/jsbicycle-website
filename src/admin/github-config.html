🔗 GitHub 自动部署配置

连接 GitHub 仓库后，Admin 编辑可一键发布到网站（自动触发 Netlify 部署）。

配置 GitHub 访问

未配置
使用步骤：
① 在 GitHub 创建空仓库（推荐私有仓库）
② 创建 GitHub Personal Access Token (classic)，勾选 repo 权限
③ 在下方填入仓库信息和 Token
④ 点"测试连接"，确认 Token 可访问该仓库
⑤ 连接成功后，去任何编辑页点"📤 发布到网站"按钮
需 repo 权限（完整仓库读写）。在 GitHub Settings → Developer settings → PAT 创建。

📤 一键发布全部

将所有本地编辑推送到 GitHub，触发 Netlify 自动部署。约 2-5 分钟生效。

发布范围：
  • news + newsDetail → src/data/news.js
  • site + navigation + footer → src/data/site.js
  • pages（包含 events / branches / wuxi-office / magazines / standards） → src/data/pages.js

📖 Netlify 关联配置（一次性）

GitHub 配置完成后，请在 Netlify 项目设置 中：

① 进入 Site settings → Build & deploy → Continuous deployment

② 把部署方式从 "Drag and drop" 改为 GitHub

③ 选择您刚创建的仓库

④ 配置 build 设置：

Base directory:（留空）

Build command: npm run build

Publish directory: dist

⑤ 开启 Auto-deploy：让每次 push main 分支都自动部署

⑥ 以后每次在 Admin 点"发布"，都会自动触发新版本部署 🎉
