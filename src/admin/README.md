## 🔧 工作流程

1. **登录** → 输入账号密码进入仪表盘
2. **进入编辑页** → 点击仪表盘的快速入口或左侧菜单
3. **修改内容** → 直接在表格/表单中编辑
4. **保存到本地** → 点击表单底部"保存所有修改到本地"
5. **导出 JSON** → 点击仪表盘顶部"📦 完成编辑后操作"卡片的"导出全部 JSON"按钮，会下载一个 `jbbea-admin-2026-08-17.json` 之类的文件
6. **发送给我** → 把下载的 JSON 文件发给运维同事（我），我会合并到项目代码并重新部署

## 📝 新闻编辑器特色

针对您从公众号复制粘贴的需求做了优化：

- **三栏分类** 自动归类（协会动态 / 行业资讯 / 政策动态）

- **快捷工具** 一键插入段落 / 标题 / 加粗

### 推荐发布流程

1. 在公众号编辑器里复制整篇文章
2. 打开新闻编辑器，标题、日期、分类自动填充
3. 把公众号复制的内容粘贴到"详情正文"文本框
4. 上传公众号里的图片（多张可以一张一张上传）
5. 保存并导出

## 💾 数据存储说明

- 所有改动保存在 **浏览器本地**（LocalStorage），关闭浏览器不会丢失
- 服务器只保存 **初始默认数据**，编辑后请导出 JSON 并发送给我部署
- **重新加载默认** 按钮会丢弃本地改动，重新从服务器加载
