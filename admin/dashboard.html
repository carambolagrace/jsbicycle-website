使用提示

① 各模块编辑入口在上方"快速入口"区域，点击进入对应编辑页。

② 新闻资讯编辑器支持从公众号复制粘贴（标题、日期、分类、正文），并可直接上传图片。

③ 所有改动实时保存到浏览器本地（LocalStorage），关闭浏览器不会丢失。

④ 编辑完成后，点击左侧"导出全部"按钮，下载一个 JSON 文件并发给运维同事部署上线。

⑤ 每次部署后，浏览器会自动从远端 JSON 重新加载最新数据。
